# WattScape Backend

Java 21+ Spring Boot resource server with PostgreSQL, Flyway, JPA, Bean Validation, OpenAPI, structured logging, and tenant-scoped `/api/v1` endpoints.

Start and provision instructions are in `../docs/BACKEND-SETUP.md`. Endpoint behavior is documented in `../docs/API.md`. This service requires an external OIDC issuer and does not issue tokens.
